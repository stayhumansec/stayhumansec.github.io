// HOW TO ACTUALLY USE THIS

A recovery kit only works if it's actually recoverable.

Never store this on the same phone it's meant to recover

If your phone is what's lost, stolen, or broken, a note saved on it doesn't help. Print this, or save it somewhere you can reach from a different device — a password manager's secure notes, a printed copy in a drawer, or with someone you trust.

Never write the actual codes here

This tool is for tracking which method recovers each account, not the backup codes themselves. Keep the real codes wherever your password manager or the account's own instructions recommend.

Start with the accounts that matter most

Your primary email first — it can usually reset everything else. Then banking, then anything with 2FA you'd genuinely be stuck without.

Everything stays in your browser

This list is saved to this browser's local storage only — nothing is sent anywhere. Clearing your browser data will clear this list too, so print or export it once it's useful.
